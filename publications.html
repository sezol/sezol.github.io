River Publishers · 2022

Survey on Banker's Algorithm to Remove Deadlock

A survey of the Banker's Algorithm, the classic operating-systems method for deciding whether it's safe to grant a resource request. Before approving any request, the system simulates granting it and checks whether every process could still finish given what's left — if yes, it's a safe state; if no process could ever finish, the system is heading toward deadlock.

IRJET · Jan 2022

Dijkstra's Shortest Path Visualization

A visualization of Dijkstra's algorithm — the same idea behind how Google Maps picks a route. Starting from a source node, the algorithm keeps track of the shortest known distance to every other node, and greedily expands outward from whichever unvisited node is currently cheapest to reach. It only works correctly when every edge weight is non-negative.
